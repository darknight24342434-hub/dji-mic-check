# DJI 麥克風工具（純本機）

把 DJI 無線領夾麥克風的接收端接到電腦，當成一般 Windows 錄音裝置來用。這裡的工具負責**查裝置、測訊號、設定輸入來源**——全部只呼叫本機的 ffmpeg，**不連任何外部服務、不需要任何 API key、不花錢**。

**轉文字不在這裡。** 語音轉文字請自行搭配本地的離線聽寫工具（例如 faster-whisper）。

> 變更紀錄：本工具早期的轉寫功能會把錄音上傳到雲端 API，需要付費金鑰，已整段移除（`once` / `loop` 兩個子命令與對應的啟動腳本）。現在只保留純本機的 `devices` / `record`。

## 硬體接法

**採用的接法＝3.5mm 耳機線轉接**（實測確認可行）：

1. **先確認發射端和接收端已配對**——接收端螢幕要看得到發射端，對著發射端講話時音量條要跳動。**這一步不成立，後面接什麼線都不會有聲音。**
2. 發射端拿在手上或夾在衣領，確認沒有被靜音（發射端有靜音鍵）。
3. 接收端的 3.5mm 輸出孔，用耳機線接到電腦的**麥克風孔**（不是耳機孔）。
4. 插上後 Windows 錄音裝置清單會多出主機板音效卡的麥克風端點（常顯示為 `麥克風 (High Definition Audio Device)` 之類的名稱）。
5. Windows 設定 > 系統 > 音效 > 輸入，選到它。

**關於 USB Type-C 接法**：理論上 DJI 接收端可當 USB 音訊裝置（某次測試中確實偵測到名為 `Wireless Microphone RX` 的裝置），但在另一台機器上實際試過**不能用**，才改走耳機線轉接。當時「不能用」的具體症狀沒有查清楚（沒出現裝置？出現但沒聲音？），所以 USB 路線的可行性〔未驗證〕，不要拿它當建議接法。

## 列出錄音裝置

```powershell
cd <這個 repo 的資料夾>
.\List-Devices.ps1
```

沒插接收端的話，清單裡不會出現 DJI。插上後再跑一次。

## 測試收音訊號

```powershell
.\Test-DJI-Mic.ps1
```

PowerShell 擋住 `.ps1` 的話改跑 `.\Test-DJI-Mic.cmd`。

看輸出的 `max_volume`：

| 數值 | 判讀 |
|---|---|
| −6 ~ −20 dB | 正常，可以用 |
| 低於 −35 dB | 太小聲，辨識會很差，要調高 DJI 或 Windows 的輸入增益 |
| 接近 0 dB | 太大聲，會爆音 |

**判斷有沒有真的收到聲音，要比較「講話時」和「沒講話時」的數值。**兩者只差幾 dB 就代表訊號沒進來，不是音量小的問題。

## 把 DJI 設成只當輸入裝置

插上 DJI 後如果電腦的聲音被搶去 DJI 的耳機孔，跑這支把它設成只當錄音裝置：

```powershell
.\Set-DJI-InputOnly.ps1
```

## 常用指令

```powershell
python .\voice_input.py devices                                  # 列裝置
python .\voice_input.py record --device DJI --seconds 5 --output test.wav   # 錄 5 秒
python .\voice_input.py record --device 2 --seconds 5 --output test.wav     # 用編號指定
```

`--device` 支援完整名稱、部分名稱（不分大小寫）或編號。名稱含中文時建議改用編號或純 ASCII 的片段，避免命令列編碼問題。

## 建議設定

- DJI 接收端輸出先設 `Mono`，單人語音比較穩。
- 輸入增益不要太高，講話大聲時不要爆音。
- 電腦風扇聲大時開 DJI 的降噪或低切；但咬字被吃掉就把降噪調弱。

## 疑難排解

**排查順序固定：先確認無線鏈路，再查電腦端。**上游斷了的時候，在電腦端怎麼量都只會量到雜訊，而且數字看起來像「音量太小」，會把人帶去調錯的東西。

| 症狀 | 處理 |
|---|---|
| **講話與不講話的音量沒差**（差幾 dB 而已） | **先看接收端螢幕**：有沒有顯示發射端、講話時音量條跳不跳。不跳＝無線鏈路斷了，去配對／解除靜音／充電，**不要在電腦端調任何東西**。實測踩過的坑就是這一項 |
| 接收端有跳、電腦收不到 | 才輪到查電腦端：耳機線是否插在麥克風孔（不是耳機孔）、Windows 輸入音量與靜音、線材是否接觸不良 |
| 音量偏小但收得到 | 調高接收端輸出增益或 Windows 輸入音量，目標把 `max_volume` 拉到 −6 ~ −20 dB |
| 想要轉成文字 | 用本地的離線聽寫工具，不要回頭找雲端 API |
